# PSL V2 browser assets

Generate this directory's model and JSON assets from the verified Python
artifacts before enabling PSL mode in the web studio:

```powershell
python training\psl\export_psl_web_assets.py
python training\psl\convert_psl_v2_to_tfjs.py
```

The exporter uses only the existing TensorFlow environment; it does not need
the heavyweight `tensorflowjs` Python package. `model.json` and its weight
shard are generated by the second command.
