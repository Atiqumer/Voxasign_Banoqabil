How to use VoxaSign

Start here if you are new. The studio will guide you through the same order.

1

Choose a language

Select American Sign Language (ASL) or Pakistan Sign Language (PSL) before starting recognition.

2

Choose your input

Use a live camera for real-time recognition, or upload a clear photo of one hand sign.

3

Read or build words

Review the result and add recognized signs to the word area when you want to create text.

Pick the right mode

Each mode uses its own trained model. Choose the language that matches the sign you are showing.

ASL mode

American Sign Language

Recognizes static alphabet signs. Results below the confidence threshold are hidden to avoid unreliable letters.

PSL mode

Pakistan Sign Language

Recognizes 36 static PSL signs. Keep your hand clearly visible and use a well-lit image for the best result.

Good to know: VoxaSign currently recognizes static hand signs. Motion-based signs are not yet supported.
